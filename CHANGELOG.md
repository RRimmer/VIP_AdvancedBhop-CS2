# История изменений

## 0.1.0

- При удержании прыжка горизонтальная скорость ограничена значением 300 единиц/с при значении 0 (по умолчанию). Положительное bhop_max_speed задаёт собственный потолок.
- При отсутствии сигнатуры ProcessMovement прыжки работают через OnTick. При конфликте имён в логе указывается сборка владельца Bhop.
- Сервер задаёт вертикальную скорость при удержании прыжка на земле. Аудит пропускает нечитаемые значения и подавляет повторную отправку при одном и том же расхождении.
- Настройки перенесены в VIPCore/Modules/VIP_Advanced_Bhop.jsonc. Комментарии описывают каждый параметр. При обновлении перенесите свои значения из прежнего файла.
- Архив содержит плагин Bhop с переводами, конфигурацию и инструкции. Панель и её capability поставляются через отдельную сборку PMM_VIPCore.
- Для работы в режиме чата достаточно VIPCore и CounterStrikeSharp.
- Порт VIP_Bhop 2.1 на CS2 с индивидуальным кулдауном, настраиваемым временем доступа к Bhop, ограничением после урона и аудитом клиентских ConVar.
- Золотой контур, отдельные тосты MenuManager, персональный формат в !vip и установка sv_legacy_jump 1.
- При удержании прыжка на земле модуль снимает состояние опоры и использует sv_jump_impulse для первого отрыва и 85 % этого импульса для немедленного повторного отрыва при удержании прыжка. Для сравнения со штатной распрыжкой задайте bhop_max_speed = -1: дополнительный лимит скорости плагина отключится.
- Чатовые уведомления используют локализованный префикс vip.Prefix из VIPCore.
- При bhop_allowtime = 0 панель скрывается через пять секунд активности; блокировка после урона снова показывает таймер.
- Плавное появление и скрытие HUD. Добавлена настройка bhop_hud_autohide_seconds для бессрочных состояний и пистолетного раунда.

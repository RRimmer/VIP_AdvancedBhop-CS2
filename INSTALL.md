# VIP Advanced Bhop для CS2

Модуль для Linux x64, CounterStrikeSharp 1.0.380 и Fabius VIPCore 2.0.3. Для сборки на Windows нужен .NET SDK 10. Из каталога проекта запустите `pack.cmd`. Рядом появится `VIP_Advanced_Bhop-CS2.zip`.

## Установка

1. Остановите сервер. Если установлен штатный `VIP_Bhop`, уберите его из каталога плагинов. Оба модуля регистрируют функцию `Bhop`.
2. Распакуйте каталог `addons` из архива в `game/csgo`. При обновлении сохраните свой JSON, если уже меняли настройки.
3. Настройки находятся в `csgo/addons/counterstrikesharp/configs/plugins/VIPCore/Modules/VIP_Advanced_Bhop.jsonc`. Если файла нет, модуль создаёт его при загрузке модуля. При обновлении перенесите изменённые значения из прежнего JSON. После редактирования перезагрузите плагин или сервер.
4. Для Panorama соберите PMM_VIPCore отдельно его собственным `pack.cmd`, установите обновление PMM и пересоберите клиентский аддон с его файлами Panorama. Без PMM уведомления выводятся в чат.
5. В существующей группе `vip.json` задайте целое число, например `"Bhop": 5`. Значение 5 означает задержку 5 секунд, 1 использует `bhop_locktime`, 0 разрешает Bhop сразу после заморозки. Чтобы отключить Bhop на пистолетных раундах, добавьте строку `"Bhop"` в существующий массив `DisableOnPistolRound` файла `vip_core.json`. Запустите сервер.

## Настройки

| Параметр | По умолчанию | Действие |
| --- | --- | --- |
| bhop_allowtime | 5 | Сколько секунд доступа к Bhop. 0 — до конца раунда |
| bhop_locktime | 15 | Начальная задержка после заморозки и повторный кулдаун для группы со значением 1 |
| bhop_info | 2 | 0 выключено, 1 ChatOnly, 2 PmmOnly, 3 чат и Panorama. При отсутствии capability режимы 1–3 выводят одно сообщение в чат |
| bhop_notify | 0 | 0 оповещает также остальных игроков, 1 оставляет персональные сообщения VIP. Урон получает отдельное оповещение у пострадавшего |
| bhop_restrict_type | 0 | 1 блокирует Bhop при получении урона от противника |
| bhop_restrict_time | 2 | Длительность блокировки в секундах. Повторный урон продлевает её |
| bhop_first_round_off | 0 | Дополнительная блокировка в пистолетных раундах по определению VIPCore, кроме разминки |
| bhop_stability_audit_interval | 0.25 | Интервал проверки обеих клиентских реплик в секундах. 0 отключает аудит |
| bhop_stability_audit_force | 1 | 1 исправляет каждое читаемое расхождение один раз. Пустой или неизвестный ответ пропускается |

На сервере отключите глобальные `sv_autobunnyhopping` и `sv_enablebunnyhopping`, если Bhop должен быть привилегией VIP. При потере доступа модуль восстанавливает клиенту серверные значения.

## Проверка на сервере

- Подключите VIP с `Bhop = 5` и обычного игрока. Удерживайте прыжок после заморозки. Проверьте первую задержку, время доступа к Bhop, повторный кулдаун и движение обычного игрока.
- Включите блокировку после урона. Проверьте попадание противника, повторное попадание, попадание союзника и истечение времени доступа к Bhop во время блокировки.
- Проверьте отключение в `!vip`, смену карты, повторный вход в тот же слот и первый раунд после смены сторон.
- Проверьте режимы 1–3 с PMM и без него. В режиме 2 с обновлённым аддоном уведомление видно при закрытом меню. Для проверки аудита сбросьте одну реплику другим серверным плагином пока Bhop доступен.
- Если сигнатура ProcessMovement отсутствует, модуль обрабатывает отрыв от земли на серверном тике. Если имя Bhop занято, лог укажет сборку владельца.

## HUD и уведомления

При загрузке и смене карты Bhop выполняет серверную команду sv_legacy_jump 1. Она действует на всех игроков.
Для HUD обновите PMM_VIPCore 0.1.6 его собственным pack.cmd, включая shared/PmmNotificationApi и Panorama из Content-addonmanager. Тосты используют штатные уведомления MenuManager с настройками сервера и игрока.
В JSONC bhop_display_mode задаёт формат (1 — тост, 2 — таймер, 3 — оба), bhop_hud_position — место (0 — под радаром, 1 — под счётом, 2 — под прицелом, 3 — над HP). По умолчанию включены оба элемента под настройкой сервера.
Чтобы разрешить выбор, включите bhop_player_display_settings и добавьте "BhopHud": 1 в группу с "Bhop" в vip.json. В !vip появится BhopHud. Выбор хранится в cookie VIPCore.

Параметр bhop_max_speed задаёт потолок горизонтальной скорости в единицах/с при активном Bhop и удержании прыжка. По умолчанию и при отсутствии поля используется 0 — потолок 300 единиц/с.

При удержании прыжка на земле модуль снимает состояние опоры и использует sv_jump_impulse для первого отрыва и 85 % этого импульса для немедленного повторного отрыва при удержании прыжка. Для сравнения со штатной распрыжкой задайте bhop_max_speed = -1: дополнительный лимит скорости плагина отключится.

Параметр bhop_hud_autohide_seconds задаёт задержку скрытия бессрочных Active и Inactive, включая блокировку в пистолетном раунде. По умолчанию 5 секунд. При 0 панель остаётся видимой. Конечный отсчёт отображается до завершения.
